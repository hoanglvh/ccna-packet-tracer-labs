no ip domain-lookup
enable secret class
line console 0
 password cisco

!

 passive-interface GigabitEthernet0/0/0
!

 ip ospf 10 area 0
 no shutdown

 description to R1

 ip ospf network point-to-point
 ip ospf 10 area 0
 no shutdown
interface GigabitEthernet0/0/2
 description to R3
 ip address 10.0.23.1 255.255.255.252
 ip ospf network point-to-point
 ip ospf 10 area 0
 no shutdown
!
